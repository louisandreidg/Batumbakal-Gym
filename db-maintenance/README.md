# Activity 5 Maintenance and Monitoring

[Progress report](../docs/Activity5-Progress-Report.pdf)

Each group folder contains health checks, query plans, maintenance commands and results. execution-records.json records the commands and accounts used. shared-log-review.json contains the server log findings.

Maintenance completed where the existing account had ownership or MAINTAIN. G01/G03 could not authenticate during this activity. G05/G08 did not have maintenance permission. These limitations are recorded in their folders.

The checks used small local databases. Query timings are individual observations, and restricted accounts may not see other users session details. Most shared log entries do not identify a database or account.

Review the local credential and PostgreSQL paths before running the scripts. Feedback files are drafts and have not been sent.
