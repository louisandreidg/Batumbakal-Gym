# Shared Project Tests

These files cover G04 HealthBridge, G05 SHIORI, G06 Car Rental and G08 Catering.

- permission-results.json contains the original SQL, account, expected result, actual result and output.
- application-results.json contains HTTP test results.
- test-permissions.ps1 is the shared permission test script.
- setup-adaptations.log records the local setup changes.
- connection-policy.snippet contains the account-specific connection rules used for these projects.

Use the project field to identify each result. Item numbers match verification-results.csv. Project-specific setup and workflow logs remain in the individual folders.
